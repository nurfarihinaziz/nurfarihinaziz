# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow patients to register, log in, and manage their personal profiles securely.

2. The system shall allow patients to search for doctors, healthcare services, and available appointment slots.

3. The system shall allow patients to book, reschedule, and cancel healthcare appointments online.

4. The system shall provide an AI-powered chatbot to answer common appointment-related questions and assist patients with the appointment booking process.

5. The system shall send appointment confirmations, reminders, and notifications to patients regarding their scheduled appointments.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display search results and appointment availability within 3 seconds under normal operating conditions.

2. The system shall protect patient information through secure authentication and encrypted data transmission.

3. The system shall provide a user-friendly and responsive interface that supports desktop computers, tablets, and mobile devices.
