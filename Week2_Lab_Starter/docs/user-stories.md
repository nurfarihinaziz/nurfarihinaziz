# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a patient, I want to search for available doctors and appointment slots, so that I can choose a suitable doctor and convenient appointment time.

2. As a patient, I want to interact with an AI-powered chatbot, so that I can receive assistance with appointment bookings and get answers to common appointment-related questions.

3. As a clinic administrator, I want to manage doctor schedules and patient appointments, so that I can prevent scheduling conflicts and ensure appointments are organised efficiently.

4. As a doctor, I want to view my daily appointment schedule, so that I can prepare for upcoming patient consultations.
